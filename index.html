Como obter Bin ID e Master Key?
  1. Crie conta grátis em jsonbin.io
  2. No painel, clique em API Keys → copie sua X-MASTER-KEY
  3. Clique em Create Bin → cole {} como conteúdo → clique em Create
  4. Copie o Bin ID que aparece na URL (após /b/)
  5. Cole os dois campos acima e clique em Testar conexão
